3. Questo programma utilizza l'intelligenza artificiale
Vibisual funziona utilizzando l'intelligenza artificiale (IA) generativa, come Claude di Anthropic. Le risposte, il codice, le valutazioni e i riepiloghi mostrati sullo schermo sono prodotti dall'IA e non sono stati esaminati da una persona.

4. Cosa avviene su questo computer
Entro i limiti delle cartelle che l'utente affida e delle autorizzazioni che concede, gli agenti di IA possono leggere, creare, modificare ed eliminare file, eseguire comandi e accedere a Internet.
Inoltre, Vibisual stesso svolge le seguenti operazioni. (1) Al primo avvio aggiunge un'impostazione di connessione (hook) al file di impostazioni di Claude Code (~/.claude/settings.json); se tale file esiste già, ne viene conservata una copia di backup accanto al file stesso. (2) Può installare o aggiornare Claude CLI (gli aggiornamenti automatici della CLI possono essere disattivati nelle opzioni). (3) Quando viene rilasciata una nuova versione, si aggiorna automaticamente (non esiste alcuna impostazione per disattivare l'aggiornamento automatico). (4) Gestisce i processi avviati dai propri agenti e può terminarli quando l'utente interrompe un'attività o chiude l'app, oppure quando esegue la pulizia di un'attività che ritiene conclusa o bloccata; per tale valutazione può essere utilizzata l'IA. (5) L'acquisizione dello schermo, l'accesso remoto (telefono, codice QR, esposizione su Internet), i collegamenti a servizi di messaggistica (Discord, Telegram) e il download di modelli locali funzionano solo quando l'utente li attiva.

L'utente decide quali cartelle affidare, quali autorizzazioni concedere e quali funzioni attivare, ed è responsabile dei risultati.

6. Output dell'IA
L'IA può produrre codice errato, vulnerabilità di sicurezza, affermazioni non veritiere oppure output che viola il diritto d'autore o le licenze di terzi. Spetta all'utente esaminare l'output prima di utilizzarlo, distribuirlo o eseguirne il commit, nonché verificare i diritti e le licenze che esso richiede.

7. Rischi per la sicurezza
Istruzioni malevole nascoste in repository, pagine web, documenti, issue od output di comandi (prompt injection) possono ingannare l'IA e indurla a eseguire comandi non voluti dall'utente o a inviare informazioni all'esterno. Restringere le autorizzazioni quando si lavora con materiale non attendibile. Se l'utente affida all'IA una cartella o una schermata che contiene password, chiavi API o dati personali, tale contenuto può essere inviato al servizio di IA. Se l'utente espone l'accesso remoto su Internet o collega un servizio di messaggistica, chiunque ottenga le informazioni di connessione può comandare gli agenti presenti su questo computer; pertanto l'utente deve custodire tali informazioni in modo sicuro.
