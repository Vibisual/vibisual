4. What happens on this computer
Within the folders you hand over and the permissions you grant, AI agents can read, create, change, and delete files, run commands, and access the internet.
Vibisual itself also does the following. (1) On first launch it adds a connection setting (hooks) to the Claude Code settings file (~/.claude/settings.json); if that file already exists, a backup is kept beside it. (2) It may install or update the Claude CLI (automatic CLI updates can be turned off in Options). (3) When a new version is released, it updates itself automatically (there is no setting that turns this off). (4) It manages the processes its agents start, and may end them when you stop a task or close the app, or when it cleans up a task it judges to be finished or stuck; AI may be used to make that judgment. (5) Screen capture, remote access (phone, QR code, exposure to the internet), messenger connections (Discord, Telegram), and local model downloads work only when you turn them on.
