3. Dieses Programm nutzt KI
Vibisual funktioniert, indem es generative künstliche Intelligenz (KI) nutzt, etwa Claude von Anthropic. Antworten, Code, Einschätzungen und Zusammenfassungen, die auf dem Bildschirm angezeigt werden, werden von KI erzeugt und wurden nicht von einem Menschen geprüft.

4. Was auf diesem Computer geschieht
Innerhalb der Ordner, die Sie übergeben, und der Berechtigungen, die Sie erteilen, können KI-Agenten Dateien lesen, erstellen, ändern und löschen, Befehle ausführen und auf das Internet zugreifen.
Vibisual selbst tut außerdem Folgendes. (1) Beim ersten Start fügt es der Einstellungsdatei von Claude Code (~/.claude/settings.json) eine Verbindungseinstellung (Hooks) hinzu; ist diese Datei bereits vorhanden, wird daneben eine Sicherungskopie aufbewahrt. (2) Es kann die Claude CLI installieren oder aktualisieren (automatische CLI-Updates lassen sich in den Optionen deaktivieren). (3) Wenn eine neue Version veröffentlicht wird, aktualisiert es sich automatisch selbst (es gibt keine Einstellung, mit der sich dies deaktivieren lässt). (4) Es verwaltet die Prozesse, die seine Agenten starten, und kann sie beenden, wenn Sie eine Aufgabe stoppen oder die App schließen oder wenn es eine Aufgabe bereinigt, die es als abgeschlossen oder hängengeblieben einschätzt; für diese Einschätzung kann KI eingesetzt werden. (5) Bildschirmaufnahme, Fernzugriff (Mobiltelefon, QR-Code, Freigabe ins Internet), Messenger-Verbindungen (Discord, Telegram) und das Herunterladen lokaler Modelle funktionieren nur, wenn Sie sie einschalten.
